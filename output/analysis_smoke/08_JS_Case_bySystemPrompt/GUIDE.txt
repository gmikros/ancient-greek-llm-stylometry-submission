ANALYSIS 07-08: JS DIVERGENCE BY SYSTEM × PROMPT
═══════════════════════════════════════════════════════════════════════

WHAT THIS SHOWS:
- STRATIFIED JS divergence: Each system×prompt combination compared 
  to Human originals separately
- Which system (Claude vs GPT) better preserves style
- Which prompt strategy (Free vs Restricted) is more faithful
- How these effects vary by author

VARIABLES INVOLVED:
- Category1 (System): Claude, GPT
- Category2 (Author): 10 authors
- Category3 (Prompt): Free, Restricted
- Category4 (Label): Human vs AI
- Feature family: mood_ or case_ features

CALCULATION:
For each author × system × prompt:
1. Get Human originals for this author → distribution P
2. Get AI rewrites for this specific system+prompt → distribution Q
3. Compute JS(P||Q)

Example: Demosthenes-Claude-Free vs Demosthenes originals

FILES GENERATED:
- js_by_system_prompt_author.csv - Long-format table (author×system×prompt×JS)
- js_system_prompt_heatmap.png - Heatmap (rows=system×prompt, cols=authors)
- js_boxplot_by_system_prompt.png - Box plots showing variability across authors
- js_prompt_effect_slopes.png - Slope graph (Free→Restricted per author)
- js_combined_slide.png - **PRESENTATION SLIDE** (by-author + system×prompt in one)

RESEARCH QUESTIONS:
1. Is Claude or GPT better at preserving Ancient Greek style?
2. Do Free or Restricted prompts allow closer mimicry?
3. Does the best system depend on the prompt? (interaction effects)
4. Are some authors better preserved by specific configurations?

INTERPRETATION:
Heatmap patterns:
- Darker colors = higher divergence (worse preservation)
- Lighter colors = lower divergence (better preservation)
- Compare rows: Which system×prompt is consistently best?
- Compare columns: Which authors are consistently difficult?
- Look for interactions: Is Claude-Free best for some, GPT-Restricted for others?

STATISTICAL ANALYSIS YOU CAN DO:
From the CSV:
- Two-way ANOVA: Effect of System, Prompt, and interaction
- Post-hoc tests: Pairwise comparisons
- Author-specific tests: Does pattern vary by author?

ADDITIONAL VISUALIZATIONS:

Box Plot (js_boxplot_by_system_prompt.png):
- Shows JSD distribution across authors (not just mean)
- Boxes reveal variability and outliers
- Wider boxes = inconsistent across authors
- Narrow boxes = consistent preservation quality

Slope Plot (js_prompt_effect_slopes.png):
- Each line = one author
- Left point = Free prompt JSD
- Right point = Restricted prompt JSD
- Downward slope → Restricted improves (lowers JSD)
- Upward slope → Restricted worsens (raises JSD)
- Thick lines = system averages
- Light blue/red = individual authors (Claude/GPT)
- Dark blue/red = system averages

INTERPRETATION OF SLOPES:
- Most lines slope down → Restricted generally better
- Most lines slope up → Free generally better
- Lines cross each other → prompt effect varies by author
- Parallel lines → consistent prompt effect
