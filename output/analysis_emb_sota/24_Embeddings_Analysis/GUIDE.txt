WHAT THIS SHOWS:
- Analysis of 50-dimensional embeddings from Ancient-Greek-BERT model

- Validation of stylometric findings using neural embeddings
- Assessment of embedding-based vs feature-based approaches

EMBEDDING MODEL:
- Model: pranaydeeps/Ancient-Greek-BERT
- Dimensions: 50 (mean pooling of last hidden state)
- Input: Full text (truncated to 512 tokens)
- Output: Document-level embedding vector

VARIABLES INVOLVED:
- WE1-WE50: 50 embedding dimensions
- Category1 (System): Claude, GPT, Human
- Category2 (Author): 10 Ancient Greek authors
- Category3 (Prompt): Free, Restricted, Human
- Category4 (Label): AI, Human

RESEARCH QUESTIONS:
1. Do embeddings capture the same stylistic differences as features?
2. Are embeddings more/less discriminative than stylometric features?
3. Do both methods agree on difficult authors and best systems?
4. Are embeddings complementary or redundant with features?

INTERPRETATION GUIDE:

High Correlation (r > 0.7):
-> Embeddings and features capture similar stylistic information
-> Methods provide convergent validity
-> Embeddings could replace features for efficiency

Moderate Correlation (r = 0.4-0.7):
-> Methods capture complementary information
-> Embeddings may focus on semantic content
-> Features may focus on grammatical patterns
-> Combined approach recommended

Low Correlation (r < 0.4):
-> Methods capture different aspects of style
-> Embeddings: semantic, contextual, lexical
-> Features: grammatical, structural, morphological
-> Both methods provide unique insights

EXPECTED FINDINGS:
- Embeddings likely more sensitive to semantic content
- Features likely more sensitive to grammatical patterns
- Both should identify Human vs AI separation
- Agreement on systemxprompt ranking validates findings
- Disagreement on author difficulty suggests different "signatures"

PRACTICAL IMPLICATIONS:
- If embeddings perform well: Simpler, more efficient approach
- If features perform better: Grammatical patterns more diagnostic
- If both needed: Comprehensive stylometric profile
- Cross-validation increases confidence in findings

NEXT STEPS:
- Use embedding-feature agreement to validate key findings
- Investigate cases where methods disagree
- Consider ensemble approaches combining both
- Explore which embedding dimensions correlate with which features
