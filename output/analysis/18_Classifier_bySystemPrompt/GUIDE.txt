ANALYSIS 18: CLASSIFIER PER SYSTEM × PROMPT
═══════════════════════════════════════════════════════════════════════

WHAT THIS SHOWS:
- Condition-specific detectability: How detectable is each 
  system×prompt combination?
- Which configurations produce more human-like texts
- Interaction between system and prompt in detectability

VARIABLES INVOLVED:
- Category1 (System): Stratification variable
- Category3 (Prompt): Stratification variable
- Category4 (Label): Human vs AI
- All numeric features

CALCULATION:
For each system × prompt:
1. Subset: Human texts + AI texts from this specific condition
2. Train classifier (same method as #17)
3. Evaluate AUROC and Brier score

RESEARCH QUESTIONS:
1. Is Claude or GPT more detectable?
2. Do Free or Restricted prompts produce more detectable texts?
3. Does detectability depend on system×prompt combination?
4. Which configuration produces least detectable AI?

INTERPRETATION:
Compare AUROC across conditions:
- Lowest AUROC = most human-like (hardest to detect)
- Highest AUROC = most AI-like (easiest to detect)

Look for interactions:
- If Claude-Free has low AUROC but Claude-Restricted high → 
  prompt matters for Claude
- If systems respond differently to prompts → interaction

EXAMPLE:
Claude-Free: AUROC = 0.75 (best - least detectable)
GPT-Free: AUROC = 0.88 (worst - most detectable)
→ Claude with Free prompts is hardest to detect

performance_interaction_plot.png:
- **Line graph**: X=Prompt, Y=AUROC
- **Blue line**: Claude (Free → Restricted)
- **Red line**: GPT (Free → Restricted)
- **Shows**: Interaction between system and prompt

INTERPRETATION:
- **Parallel lines**: Prompt has same effect on both systems
- **Crossing lines**: INTERACTION! Effect of prompt depends on system
- **Downward slope**: Restricted reduces detectability (good)
- **Upward slope**: Restricted increases detectability (bad)
- **Flat line**: Prompt doesn't matter for this system

EXAMPLE:
```
Claude: Free (0.82) → Restricted (0.75)  [downward]
GPT:    Free (0.88) → Restricted (0.85)  [downward]
→ Both systems: Restricted helps (lowers AUROC)
→ Parallel slopes: Consistent prompt effect
```
