ANALYSIS 19: COMPOSITE PREDICTION PROBABILITY DISTRIBUTIONS
═══════════════════════════════════════════════════════════════════════

WHAT THIS SHOWS:
- Unified view of prediction probabilities across ALL system × prompt combinations
- How well the classifier separates Human from AI for each condition
- Overlap and separation patterns between true labels and predictions
- Comparative detectability across different configurations

VARIABLES INVOLVED:
- Category1 (System): Claude vs GPT
- Category3 (Prompt): Free vs Restricted
- Category4 (Label): Human vs AI (true labels)
- All ~107 numeric stylometric features (used for classification)
- Predicted probabilities from Logistic Regression classifier

CALCULATION:
For each system × prompt combination:
1. Train Logistic Regression classifier with cross-validation
2. Generate predicted probabilities for each sample (0-1 scale)
3. Aggregate predictions across all conditions
4. Visualize distributions by true label and condition

FILES GENERATED:
- all_predictions_composite.csv - All predictions with metadata
- composite_prediction_distributions.png - **MAIN PLOT** (overlapping histograms)
- composite_violin_plot.png - Violin plots by condition
- separation_quality_bars.png - Separation metric comparison
- separation_metrics.csv - Quantitative separation measures
- composite_unified_slide.png - **PRESENTATION SLIDE** (all views combined)

4. Which configuration shows the best separation quality?

INTERPRETATION:

Prediction Probability Scale:
- 0.0 = Confidently predicted as Human
- 0.5 = Ambiguous (decision threshold)
- 1.0 = Confidently predicted as AI

For TRUE AI SAMPLES (should be predicted high):
- Distribution shifted RIGHT (toward 1.0) = Good (correctly identified as AI)
- Distribution centered near 0.5 = Ambiguous (hard to classify)
- Distribution shifted LEFT (toward 0.0) = Excellent AI (evades detection)

For TRUE HUMAN SAMPLES (should be predicted low):
- Distribution shifted LEFT (toward 0.0) = Good (correctly identified as Human)
- Distribution centered near 0.5 = Ambiguous (hard to classify)
- Distribution shifted RIGHT (toward 1.0) = Misclassified

IDEAL PATTERN (Perfect Classifier):
- AI samples: All predictions near 1.0
- Human samples: All predictions near 0.0
- No overlap between distributions

REALISTIC PATTERN (Good Classifier):
- AI samples: Mean ~0.7-0.9, some overlap with threshold
- Human samples: Mean ~0.1-0.3, some overlap with threshold
- Moderate separation between distributions

POOR SEPARATION PATTERN:
- Both distributions centered near 0.5
- Extensive overlap
- Classifier cannot reliably distinguish

- **Higher bar** = Better separation = Easier to detect = Worse AI

INTERPRETATION:
- Separation > 0.5: Excellent classifier performance
- Separation 0.3-0.5: Good classifier performance
- Separation < 0.3: Poor classifier performance
- Compare bars: Which condition has LOWEST separation? → Best AI

PRACTICAL IMPLICATIONS:

Best AI Configuration (Lowest Separation):
- Use this system×prompt for generation tasks
- Hardest for humans/detectors to identify
- Most "human-like" according to classifier

Worst AI Configuration (Highest Separation):
- Avoid this system×prompt if mimicry is goal
- Easiest to detect
- Most "AI-like" according to classifier

Consistent vs Variable Performance:
- Narrow distributions → Reliable, consistent outputs
- Wide distributions → Unpredictable, variable outputs
- Consider trade-off: Consistency vs detectability

INTERPRETATION TIPS:

1. **Look at AI distributions first**: 
   - Shifted left = Good AI (hard to detect)
   - Shifted right = Bad AI (easy to detect)

2. **Check Human distributions**:
   - Should be shifted left (low predictions)
   - If shifted right = Classifier confused

3. **Compare conditions**:
   - Which has lowest mean AI prediction? → Best AI
   - Which has highest mean Human prediction? → Worst classifier

4. **Assess overlap**:
   - Minimal overlap = Clear separation
   - Extensive overlap = Ambiguous classification

5. **Consider practical threshold**:
   - If using 0.5 threshold, what % would be misclassified?
   - Could adjust threshold for better performance?
